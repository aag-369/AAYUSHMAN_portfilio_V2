# Aayushman Ghatak — Portfolio (v2)

Personal portfolio site for **Aayushman Ghatak**, a final-year B.Tech (AI/ML) student working across AI/ML, quantum computing, and cybersecurity.

**Live site:** https://aayushman-portfilio-v2.vercel.app

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command         | Purpose                     |
| --------------- | --------------------------- |
| `npm run dev`   | Start the development server |
| `npm run build` | Production build            |
| `npm run start` | Serve the production build  |
| `npm run lint`  | Run ESLint                  |
